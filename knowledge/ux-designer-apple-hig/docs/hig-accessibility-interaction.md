# Accessibility for interaction design

Source: https://developer.apple.com/design/human-interface-guidelines/accessibility (read 2026-11-26)

- Minimum contrast: up to 17 pt → 4.5:1; 18 pt or bold → 3:1 (verbatim table).
- Control size iOS: default 44×44 pt, minimum 28×28 pt.
- "Convey information with more than color alone … Offer visual indicators, like distinct shapes or icons."
- "Describe your app's interface and content for VoiceOver."
- "Support mobility-related assistive technologies" (VoiceOver, AssistiveTouch, Full Keyboard Access, Switch Control).
- Reduce Motion: reduce "automatic and repetitive animations, including zooming, scaling, and peripheral motion."
- Larger text: "at least 200 percent."
These map onto WCAG 2.2 AA in the repo's accessibility-wcag skill (1.4.1, 1.4.3, 2.5.8, 4.1.3, 1.4.10).
