# Accessibility requirements for visual design

Source: https://developer.apple.com/design/human-interface-guidelines/accessibility (read 2026-11-26)

## Contrast (verbatim table)
| Text size | Text weight | Minimum contrast ratio |
|---|---|---|
| Up to 17 pts | All | 4.5:1 |
| 18 pts | All | 3:1 |
| All | Bold | 3:1 |

## Hit targets (verbatim)
| Platform | Default control size | Minimum control size |
|---|---|---|
| iOS, iPadOS | 44x44 pt | 28x28 pt |
(WCAG 2.2 AA 2.5.8 minimum is 24×24 CSS px; Hazy uses 44×44.)

## Quoted rules
- "Convey information with more than color alone … people who are color blind may have particular difficulty with pairings such as
  red-green and blue-orange. Offer visual indicators, like distinct shapes or icons."
- "Be cautious with fast-moving and blinking animations … When this setting [Reduce Motion] is active, ensure your app … responds by
  reducing automatic and repetitive animations, including zooming, scaling, and peripheral motion."
- "Support larger text sizes … at least 200 percent."
